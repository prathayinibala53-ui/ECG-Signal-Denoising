# ECG-Signal-Denoising
Cleaned and analyzed ECG signals using filtering and FFT

IMPORTANT: Note that the code posted is very simplified due to the university's plagiarism rules. The actual project was much more detailed. 

## Overview
This MATLAB project demonstrates synchronized averaging and signal analysis of EEG-like signals.  
It showcases signal processing techniques including averaging, SNR computation, and Euclidean distance measurement.

## Features
- Generate or load EEG-like signals
- Compute synchronized averages for different trial subsets
- Visualize raw signals and averages
- Calculate SNR and Euclidean distance for each subset
- Tabulate results

## Tools
- MATLAB R2023a or later
- Signal processing toolbox (optional)
