# ECG-Signal-Denoising
Cleaned and analyzed ECG signals using filtering and FFT

## Overview
This project demonstrates techniques to clean and analyze ECG (electrocardiogram) signals.  
It applies filtering and signal processing methods to remove noise and visualize clean ECG data.

## Features
- Load ECG data (synthetic or open-source datasets)
- Apply filters (low-pass, high-pass, or bandpass)
- Plot raw vs filtered signals
- Simple signal feature extraction (peak detection, RMS)
